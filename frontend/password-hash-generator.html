🔐 Password Hash Generator

Generate SHA-256 hashes for secure password storage

📝 How to Use:

  1. Enter your desired password in the field above
  2. Click "Generate Hash" to create the SHA-256 hash
  3. Copy the generated hash
  4. Open frontend/src/config/credentials.ts
  5. Replace the ipRevealPasswordHash value with your new hash
  6. Restart your dev server
⚠️ Important: The hash is generated client-side in your browser. Make sure to update the credentials.ts file with the new hash and restart the dev server!
